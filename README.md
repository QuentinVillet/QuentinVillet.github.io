# quentinvillet.github.io

My portfolio: experience, projects, studies and skills. Live at https://quentinvillet.github.io

Static site, no build step needed to host it. To change the text, edit `build.py` and run:

```
python3 build.py
```

- `cv/Quentin_Villet_CV.pdf` is the file behind every "Download CV" button. Replace it to update the CV.
- `assets/screen-site.jpg` is the screenshot shown on the laptop in the intro.
- The MacBook model comes from [pmndrs/examples](https://github.com/pmndrs/examples) (MIT licence). Three.js is MIT too.
